# 投资笔记

## 总体理论

投资是一种市场行为。

投资的组成要素有投资标的，买入和卖出的交易行为。

投资标的区别于供消费的商品。二者最大的区别在于流动性，也就是是否有大量潜在买家。举例来说，中国的普通住房在2019年之前是投资标的，2023年之后是大宗消费品。
交易行为的目的是逐利。以股票为例，低买高卖追求价格差距是最常见的交易行为。

投资的核心在于标的选择和价格判断。

市场上可选的投资标的罗列如下： 股票，债券，基金，期货，实物贵金属，广义收藏品，商业地产，

价格判断是投资中最困难，最迷人的部分。

先考虑整体价格水平。对于整个投资市场而言，价格水平遵循最基本的供需原理。作为供应端，投资标的的变化往往是缓慢的，而需求端的变化相比之下要快的多。市场的总体价格水平基本上可以看做由需求端决定。

影响投资需求的第一个因素是流动性，即市场上可供投资的资金总量。过去半个世纪，主要资产价格都涨了很多倍，原因在于货币供应量大量增加，比财富增加的更快。以美股为例，标普指数在过去半个世纪涨了倍，而美元流通量涨了倍。

观察市场流动性，需要观察如下指标：美联储利率，美国银行隔夜拆借利率，美国财政部存款，中国央行利率，中国银行隔夜拆借利率。

影响投资需求的第二个因素是预期，即投资者结合客观因素，主观因素，对价格水平的判断。当市场中的所有参与者都认为某个资产价值低估，那么该资产的价格必然上涨。典型案例如比亚迪，电车业务爆炸式增长，带来营收大幅上升，此时公司股价飙升是可预期的。

影响预期的客观因素，需要观察以下指标：资产价格对比历史价格所处的价格水平，资产的盈利能力，资产交易参与者数量，

影响预期的主观因素，需要观察以下指标：资产的抗风险属性与市场对风险的预期，资产的未来盈利故事与市场的认可度，资产交易者的群聚效应与踩踏效应

## 投资品列表

### 一、传统金融资产 (Traditional Financial Assets)

这类资产具有较高的流动性，是大多数投资者资产配置的核心。

| 子类别           | 具体资产示例                                           | 主要特点                               |
| :--------------- | :----------------------------------------------------- | :------------------------------------- |
| **股权类**       | 股票（A股、美股等）、优先股、股票ETF、共同基金         | 代表公司所有权，追求资本增值和分红     |
| **固定收益类**   | 国债、公司债、市政债、高收益债、通胀保值债券(TIPS)     | 提供定期利息收入，价格受利率影响大     |
| **货币市场**     | 定期存款(CDs)、国库券、商业票据、货币市场基金          | 高流动性、低风险、短期现金等价物       |
| **集合投资工具** | 共同基金、交易所交易基金(ETFs)、对冲基金、私募股权基金 | 将多个投资者的资金汇集起来进行专业管理 |

### 二、实物资产与大宗商品 (Physical Assets & Commodities)

这类资产通常用于对冲通胀，或作为多元化投资的一部分。

| 子类别       | 具体资产示例                           | 主要特点                           |
| :----------- | :------------------------------------- | :--------------------------------- |
| **贵金属**   | 黄金、白银、铂金、钯金                 | 避险属性强，受美元和实际利率影响大 |
| **能源类**   | 原油（WTI、Brent）、天然气、煤炭       | 价格受全球供需和地缘政治影响       |
| **工业金属** | 铜、铝、锌、镍、铁矿石                 | 与全球工业生产和经济周期高度相关   |
| **农产品**   | 玉米、小麦、大豆、咖啡、糖、棉花、活牛 | 价格受天气、库存和消费需求影响     |

### 三、房地产及基础设施 (Real Estate & Infrastructure)

这类资产通常提供稳定的现金流，并具有长期增值的潜力。

| 子类别             | 具体资产示例                                 | 主要特点                                 |
| :----------------- | :------------------------------------------- | :--------------------------------------- |
| **房地产**         | 住宅地产、商业地产（办公楼、仓库、商场）     | 可提供租金收入和资本增值，流动性相对较低 |
| **房地产投资信托** | REITs（房地产信托投资基金）                  | 提供了一种流动性高的房地产投资方式       |
| **基础设施**       | 机场、港口、收费公路、公用事业（电力、水务） | 通常具有稳定的特许经营权或监管下的现金流 |

### 四、另类投资与收藏品 (Alternative Investments & Collectibles)

这类资产与传统市场的相关性较低，有助于分散风险。

| 子类别           | 具体资产示例                               | 主要特点                                     |
| :--------------- | :----------------------------------------- | :------------------------------------------- |
| **私募投资**     | 私募股权(PE)、风险投资(VC)、私募信贷       | 投资于非上市公司，周期长、高风险、高回报潜力 |
| **收藏品**       | 艺术品、稀有葡萄酒、古董车、稀有钱币、邮票 | 价值依赖于市场稀缺性和历史文化价值           |
| **自然资源**     | 林地、农田、水权                           | 提供生产收入和对抗通胀的能力                 |
| **知识产权**     | 专利、著作权、商标权                       | 通过许可或许可使用权产生收入                 |
| **保险相关产品** | 具有现金价值的寿险保单、万能险             | 结合保障功能和投资属性                       |

### 五、数字资产与衍生品 (Digital Assets & Derivatives)

这是新兴的资产类别，或是用于管理风险和投机的工具。

| 子类别         | 具体资产示例                                                | 主要特点                             |
| :------------- | :---------------------------------------------------------- | :----------------------------------- |
| **加密货币**   | 比特币、以太坊、稳定币、山寨币                              | 高波动性、新兴资产类别、去中心化特性 |
| **金融衍生品** | 期货（商品、股指、利率）、期权、互换(Swaps)、差价合约(CFDs) | 价值取决于标的资产，可用于对冲或投机 |

------

这个目录基本涵盖了投资者可以配置资金的所有主要方向。在实际操作中，投资者可以根据自身的财务目标、风险承受能力和市场判断，选择合适的资产组合。
